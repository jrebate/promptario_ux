# Promptario UX

Prompts en español para revisar textos, formularios, imágenes e investigación con IA pensando en todas las personas. Se copian y se pegan en la IA que use cada persona; la página no envía nada a ningún sitio.

Web: https://jrebate.github.io/promptario_ux/

## Qué hay

- 12 prompts gratis en 5 temas (textos, formularios, imágenes y vídeo, investigación, revisión), con buscador y filtro.
- Cada prompt marca en color lo que hay que cambiar (entre corchetes), pide a la IA que no invente y que pregunte, y lleva una nota «Revisa tú».
- Pack completo (más de 50 prompts, cadenas, PDF y plantilla) solo como prueba de interés: pago simbólico, Ko-fi y correo.

## Medición

GoatCounter (jrebate), eventos con prefijo `prompts-`: `prompts-copiar-<id>`, `prompts-filtro-<tema>`, `prompts-buscar`, `prompts-ir-pro`, `prompts-pro-me-interesa`, `prompts-pro-pack-completo`, `prompts-pro-cadenas`, `prompts-pro-plantilla`, `prompts-pro-equipo`, `prompts-kofi-pro`, `prompts-kofi-pie`, `prompts-contacto-email`, `prompts-ir-legible`, `prompts-ir-centaurux`.

## Técnica

HTML estático sin compilación, con el CSS base de CentaurUX.

Los prompts ayudan a revisar y a preparar borradores. No sustituyen una evaluación experta ni pruebas con personas, y no garantizan el cumplimiento de ninguna norma.
